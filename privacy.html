Privacy Policy

Last updated: October 4, 2026

Shorts Publisher ("the tool") is a private tool used by a single independent developer to manage the developer's own YouTube channels. This policy explains what data the tool accesses and how it is handled.

1. YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

2. Data the tool accesses

  • Basic information about the authorized channel (channel ID, title, description).
  • Metadata of videos uploaded to that channel (video ID, title, description, tags, privacy status, publish time).
  • Aggregated YouTube Analytics metrics for those videos (views, average view duration and percentage, likes, comments, shares, subscribers gained).

The tool does not access personal information of viewers, commenters or any other users.

3. How the data is used

The data is used only to upload and manage the owner's own videos and to review their performance in order to improve future videos.

4. Storage and security

  • The OAuth refresh token and client credentials are stored only on the owner's own computer, in a folder that is not published or shared.
  • Analytics figures are copied into the owner's private notes for comparison between videos. They are not published.
  • Stored analytics data is refreshed or deleted within 30 days, in line with the YouTube API Services Developer Policies.

5. Sharing

The tool does not sell, rent or share any data with third parties.

6. Cookies and device information

The tool is a command-line program. It does not use cookies and does not store, access or collect information on any user's device or browser.

7. Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. After revocation, the stored token is deleted, and any stored analytics data can be deleted on request to the contact address below.

8. Changes

Changes to this policy will be posted on this page with a new "Last updated" date.
